# Security

## Reporting a vulnerability

Please report suspected vulnerabilities privately using GitHub's **Report a vulnerability** option in this repository's Security tab.

Do not disclose vulnerability details, secrets, personal data or production values in public issues or pull requests. If private reporting is unavailable, contact the repository owner privately rather than posting the report publicly.

## Scope

Reports about this project's code and its handling of sensitive information are welcome. Unrelated services and third-party projects are outside this repository's scope.
